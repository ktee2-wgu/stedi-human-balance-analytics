# stedi-human-balance-analytics
Repository for Udacity STEDI human balance analytics project. 

AWS Glue and PySpark project that processes customer, accelerometer, and Step Trainer data through landing, trusted, and curated zones.
This repository contains the required SQL scripts, Glue job scripts, and Athena screenshots.
